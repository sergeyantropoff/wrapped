How to get CAPTCHA tokens

Cloudflare Turnstile

  1. Open Cloudflare Turnstile dashboard
  2. Create a site widget for your domain (use localhost for dev)
  3. Copy Site Key into the field above
  4. Copy Secret Key into env TURNSTILE_SECRET_KEY and restart
  5. Set provider to turnstile

hCaptcha

  1. Open hCaptcha dashboard
  2. New site → copy Sitekey here
  3. Secret into env HCAPTCHA_SECRET_KEY, restart
  4. Set provider to hcaptcha
